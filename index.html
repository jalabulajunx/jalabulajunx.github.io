How I work

Senior Product Manager at LexisNexis Canada (RELX) since 2020, shipping LLM products inside a regulated domain where a wrong answer has consequences.

01

Build the first version

I prototype the agentic workflow myself before asking anyone to fund it, so the conversation starts from something that runs.

02

Measure before scaling

Held-out data and blind evaluation come before rollout. If it only works on the demo, it doesn't work.

03

The expert keeps the call

I design the review step so the lawyer, editor or teacher signs off. Two hands on the wheel.
